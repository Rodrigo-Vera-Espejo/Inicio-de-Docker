## Descripción
DevMasters es una aplicación web desarrollada para la materia Tecnologías Emergentes I. El proyecto presenta información del equipo mediante una interfaz moderna con un carrusel dinámico de integrantes implementado con JavaScript.

## Características
- Diseño moderno y responsivo.
- Carrusel interactivo de integrantes.
- Cambio automático cada 5 segundos.
- Navegación mediante botones anterior y siguiente.
- Información dinámica cargada desde JavaScript.

## Tecnologías Utilizadas
- HTML5
- CSS3
- JavaScript
- Docker
- Nginx
